# Game Vision

## Short Pitch

A modern frontier-era real-time strategy game about settlement, survival, expansion, trade, conflict, and shifting territorial control. The game should preserve the readability and directness of classic RTS design while modernizing animation, UI, rendering, AI, and mission flow.

## Remake Stance

The safest current direction is a spiritual successor or clean-room remake rather than a direct reproduction. The project can study the genre and the historical reference game for design lessons, but should use original names, original assets, original code, original mission scripts, and original writing unless rights are secured.

## Design Pillars

### Readable RTS Action

Players should be able to understand the battlefield at a glance. Unit silhouettes, team colors, attack effects, movement speed, and UI feedback must remain clear when zoomed out.

### Frontier Logistics

Economy should feel physical and territorial. Workers gather, carry, construct, repair, and expose themselves to risk while expanding the player's reach.

### Faction Identity

Each faction should have distinct strengths, visual language, unit mix, and strategic rhythm. Differences should be meaningful without becoming hard to understand.

### Modern Responsiveness

The game should feel immediate on modern hardware: smooth camera movement, quick selection feedback, responsive commands, clear path previews, and low-latency UI interactions.

### Scalable Presentation

The game should support better lighting, terrain, water, foliage, VFX, animation blending, and larger unit counts than the early-2000s reference point.

## Initial Scope

The first playable version should prove the core loop:

1. Start with a command building and workers.
2. Gather two resources.
3. Place and construct buildings.
4. Train military units.
5. Scout terrain.
6. Fight enemy units and structures.
7. Destroy or capture the enemy base.

## What To Preserve In Spirit

- Frontier RTS tone and historical flavor.
- Settlement-building and map control.
- Distinct cultures/factions with different unit rosters.
- Classic RTS readability and command structure.
- Campaign missions with authored objectives.

## What To Modernize

- Widescreen UI and scalable HUD.
- Smooth camera zoom and movement.
- Higher-quality animation and VFX.
- Improved pathfinding and formations.
- Better skirmish AI.
- Accessibility settings.
- Data-driven content and mod-friendly structure.

## What To Avoid

- Using original proprietary assets or names without permission.
- Building the full content roster before the vertical slice works.
- Overdesigning simulation detail before pathfinding, combat, and economy feel good.
- Letting visuals obscure unit readability.
