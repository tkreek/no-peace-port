# Roadmap

## Phase 0: Foundation

- Create project skeleton.
- Capture design vision.
- Define legal/IP boundaries.
- Compare engines.
- Define vertical slice.
- Create initial backlog.

## Phase 1: Engine Spike

- Create a Godot 4 project.
- Prototype RTS camera.
- Prototype unit selection.
- Prototype movement and pathfinding.
- Prototype terrain and rendering.
- Test animated unit count.
- Produce macOS build.
- Produce Windows build.

## Phase 2: Vertical Slice

- Build core simulation.
- Add one faction.
- Add two resources.
- Add three unit types.
- Add three building types.
- Add basic combat.
- Add basic enemy AI.
- Add basic UI and minimap.
- Add placeholder audio and VFX.

## Phase 3: Visual Target

- Establish art direction.
- Create first polished worker unit.
- Create first polished combat unit.
- Create first polished building.
- Define animation quality bar.
- Define terrain biome quality bar.
- Add lighting and post-processing target.

## Phase 4: Content Expansion

- Add additional units and buildings.
- Add upgrades.
- Add more map types.
- Add additional factions.
- Add campaign mission scripting.
- Add save/load.

## Phase 5: Production Hardening

- Optimize unit counts.
- Improve AI.
- Improve pathfinding and formations.
- Add accessibility settings.
- Add settings menus.
- Package installers or distributable builds.
- Build QA checklist.
